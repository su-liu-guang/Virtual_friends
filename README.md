# Virtual Friends - AI 聊天伴侣插件

Virtual Friends 致力于打造“越聊越懂你”的 AI 伙伴：它会记住故事、理解语境、拥有个性，还能在寂静的时候主动来打个招呼。现在，它更是一位博学的“百事通”，能阅读你给的资料，解答各种难题。

---

## 🌟 能力亮点
- **记忆像人一样**：对话会沉淀成细节、叙事、印象三层记忆；重要信息会被单独收藏，久聊依旧记得你的生日、口味、计划。
- **读得懂文档**：不仅仅是闲聊，它能阅读你投喂的攻略、手册或设定集。无论是“食堂在哪”还是“这关怎么过”，它都能从文档里找到答案告诉你。
- **图文并茂的解说**：当聊到文档里的具体内容（比如地图、装备图鉴）时，它会贴心地把对应的图片找出来发给你，就像朋友翻相册给你看一样。
- **懂时间的陪伴**：它知道现在是什么日子、几点钟，理解“昨天”“明天早上”这种相对时间，让交流更自然。
- **人设自由切换**：可随时换上不同人格，或自定义一份专属设定，瞬间获得新的语气与风格。
- **看得见图片**：发图会自动识别内容并写成注解，哪怕隔了很久也能回想起“那张猫猫图”。
- **主动开口的朋友**：在群里长时间没人说话时，它会温柔唤醒话题；平时也会随机分享轻松闲聊，但只在你允许的时段出现。
- **白名单守礼貌**：默认安静不打扰，只有加白名单的群才会响应；随时可暂停，私聊则一直在线。

## 🎮 指令速查

| 指令 | 作用 |
|------|------|
| `/人生启动` / `/世界终结` | 在群里开启或关闭 Virtual Friends |
| `/切换人设 [名称]` | 切换 AI 的人格设定 |
| `/提示词列表` / `/查看提示词` | 查看可用人设与详情 |
| `/添加提示词 名称 提示词` | 自建新人格（支持超管/群主） |
| `/记忆状态` | 查看当前累积的记忆层级与锚点数量 |
| `/遗忘 [关键词]` | 删除包含关键词的重要记忆 |
| `/清空记忆` | 重置当前群的全部记忆数据（谨慎使用） |
| `/查看白名单` | 查看所有已启用的群 |
| `/vf帮助` | 查看完整菜单与用法说明 |

> 需要微调 AI 行为（如回复概率、主动时间段等）时，可使用 `/查看配置` + `/修改配置` 在聊天里直接调整。

## 🧩 适用场景示例
- **校园/社区百事通**：把《新生指南》或《社区手册》喂给它，它就是群里 24 小时在线的咨询台，自动回答“校车几点”、“哪里办卡”，还能顺手甩出一张路线图。
- **游戏攻略助手**：导入游戏 Wiki 或攻略文档，群友卡关时问一句，它立马告诉你通关技巧和道具位置。
- **群聊暖场**：自动记录群友日常，适时追问“昨天提到的考试怎样了”，让群氛围更有人味。
- **兴趣圈陪聊**：快速切换不同人设，匹配圈子气质，保持持续互动。
- **关怀提醒**：长期静默的群友会收到轻声问候，忙碌时段、深夜等也会遵守你设定的时间保护。

---

Virtual Friends 不追求复杂配置，只想成为你们群里最懂事、最贴心的 AI 伙伴。欢迎把它带到更多故事里。
