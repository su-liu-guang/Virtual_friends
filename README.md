# Virtual Friends - AI 聊天伴侣插件

一个具备**人类级记忆特征**的 NoneBot2 AI 聊天插件，旨在模拟真实的记忆形成与遗忘过程，为群聊和私聊提供具备长期记忆和个性化人设的 AI 伴侣。

## ✨ 核心功能

### 🧠 双轨记忆系统
系统模仿人类记忆机制，将记忆分为两类：
- **流式记忆 (Stream Memory)**：记录日常对话的流水账。随着时间推移，这些记忆会自然模糊，从"细节"逐渐转化为"叙事概括"，最终沉淀为"宏观印象"。
- **锚点记忆 (Anchor Memory)**：永久铭记重要的事实信息（如用户的生日、喜好、重要计划等），对抗遗忘。
- **自动归档**：后台自动整理记忆碎片，无需人工干预。

### ⏰ 真实时间感知
- AI 具备绝对时间观念，能理解"昨天"、"下周"、"周五"等相对时间词。
- 每条消息都标注精确时间戳，AI 知道对话发生的具体时刻。
- 记忆摘要会自动标注时间范围，形成时间线。

### 🎭 灵活的人设系统
- **配置解耦**：人设提示词（Persona）与群组配置分离，支持多群复用同一人设。
- **热切换**：通过指令即时切换 AI 的性格和角色，无需重启服务。
- **自定义**：支持添加、查看、删除自定义人设，满足不同场景需求。

### 🖼️ 智能多模态交互
- **视觉识别**：支持发送图片给 AI，AI 能识别图片内容并融入对话上下文。
- **缓存优化**：对识别过的图片进行指纹（MD5）缓存，相同图片再次发送时秒回，无需重复调用 API。
- **自动注解**：图片内容会被转化为文字注解存入记忆，即使很久以后 AI 也能回忆起当时发的图。

### 💬 主动关怀模式
- **定时关怀**：依赖 `nonebot_plugin_apscheduler` 每 45 分钟扫描一次配置过的群组，AI 可在静默时段主动开口。
- **唤醒模式**：当检测到群友长时间未发言（可配置沉默阈值）时，AI 会以更体贴的语气询问近况。
- **随机闲聊**：即使未达到唤醒阈值，也会在 5% 概率下抛出轻松话题，避免机械的固定提醒。
- **时间保护**：仅在配置的 `active_hours` 范围内生效，防止打扰用户睡眠或休息。

主动行为相关的群组配置字段位于 `data/Virtual_friends/configs/<group_id>.json`，也可通过白名单初始化自动生成：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `active_mode` | Bool | `false` | 主动发消息总开关 |
| `active_hours` | List[int, int] | `[8, 23]` | 允许主动打扰的时间段（起始小时, 结束小时，支持跨天） |
| `silence_threshold` | Int | `24` | 群友沉默多少小时后进入唤醒模式 |
| `topic_preference` | String | `"random"` | 话题偏好：`care`（关怀）、`event`（事件/热点）、`random`（日常闲聊） |

> 📌 若未安装 `nonebot_plugin_apscheduler`，主动关怀功能将自动禁用。

### 🛡️ 白名单管理机制
- **默认静默**：插件在群聊中默认关闭，防止打扰。
- **人生启动**：通过指令将群组加入白名单，开启 AI 响应。
- **世界终结**：随时可以将群组移出白名单，暂停 AI 服务。
- **私聊无界**：私聊模式下默认开启，随时陪伴。

### 📊 无感后台处理
- 所有的记忆整理、摘要生成、事实提取均在后台异步执行。
- 无论记忆库多么庞大，都不会阻塞当前的对话响应，保证秒回体验。

## 🔄 记忆运作机制

### 记忆层级
AI 的记忆不是扁平的，而是像人类一样分层级的：

1.  **L1 细节摘要**：保留最近对话的具体细节（如："今天中午吃了红烧肉"）。
2.  **L2 叙事概括**：当 L1 积累过多时，合并为一段时间的叙事（如："这周饮食比较油腻"）。
3.  **L3 宏观印象**：当 L2 积累过多时，沉淀为对用户的长期印象（如："用户偏好中式肉类料理"）。

### 整理流程
每当对话积累一定数量（默认 50 条），后台会自动触发：
1.  **摘要生成**：将散乱的对话总结为 L1 摘要。
2.  **事实提取**：从对话中挖掘重要信息（如"下周三要考试"）存入锚点记忆。
3.  **递归归档**：检查 L1/L2 数量，自动向上合并生成更高级别的记忆。
